Smart Yaka Low-Credit Detection System

An electronics project designed to detect low-credit warning signals from prepaid electricity meters. The proposed system uses an LDR sensor, ATmega328P microcontroller and HC-05 Bluetooth module to detect warning light patterns and communicate notifications to a smartphone.
